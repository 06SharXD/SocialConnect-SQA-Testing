# SocialConnect — Software QA Portfolio Project

A full-stack social media web application built specifically to demonstrate practical Software Quality Assurance, functional testing, API testing, SQL validation, defect tracking, bug fixing, and regression testing.

## Project Overview

SocialConnect is a lightweight social-media-style application where users can:

- Register and log in
- Create posts
- Like posts
- Comment on posts
- Delete their own posts
- Log out
- Persist application data using SQLite

The application was developed alongside a structured QA process to simulate a real software testing workflow.
